## 每周回顾（例程输出，每周覆盖重写）

```markdown
## W__ 回顾（日期）
- 本周最大异常：______
- 我的解释（假设）：______
- 下周唯一焦点：______
- 决策规则触发：
  - [ ] star 增速归零 且 awesome PR 未铺完 → 长尾铺设加速
  - [ ] clone 不随 star 增长 → 检查首屏价值主张 / quickstart 是否跑得通
  - [ ] 某规则误报被 ≥3 人提及 → 记入校准清单（v0.3 输入）
  - [ ] 有用户问「付费版/更多功能」≥3 次 → 启动付费层评估（STRATEGY.md）
```

## 口径备注

- 「本周」按自然周（周一至周日）；14 天窗口的 clone 数记录时注明快照日期
- 发布周数据波动大，**趋势比绝对值重要**，单周噪音不做反应（连续两期恶化才动手）
- 本站无前端分析（隐私叙事优先），漏斗数据缺位是已知取舍；付费层启动前再评估自托管 Umami
