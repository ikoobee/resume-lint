# 验证报告：resume-lint（简历体检器）

> 由 `/idea-validation` 产出 · 2026-09-14 · 本项目同时是 indie-dev-skills 体系的端到端测试

## 阶段 0：快速过滤

1. **谁的具体痛点**：求职者（尤其中文简历投外企/大厂者）不确定简历会不会被
   ATS/HR 初筛过滤，也不知道怎么改——改简历的反馈回路几乎为零。
2. **现在怎么解决**：付费订阅工具（Jobscan $49.95/月、Resume Worded $49/月）、
   国内工具会员（超级简历 WonderCV）、或人工服务（市场价 ~1200 元/小时的深度诊断、
   求职机构 1-10 万元套餐）。
3. **在哪聚集**：V2EX（求职话题）、小红书/知乎（简历攻略常青内容）、
   r/resumes、即将面试的校招群。渠道可触达。
4. **为什么是我们**：浏览器端纯本地处理 = 隐私零上传（竞品全要传简历）；
   一次性买断对抗订阅疲劳；"lint" 概念对开发者受众天然友好。

## 阶段 1：社区研究（2026-09-14 实际检索）

| 证据 | 数据 | 含义 |
|---|---|---|
| [Jobscan 定价](https://app.jobscan.co/plan) | $49.95/月、$89.95/季、~$179/年；免费仅 5 次/月 | 订阅贵、免费额度极低 → 买断+免费基础有空间 |
| [Resume Worded Pro](https://resumeworded.com/get-pro) | $49/月 / $229/年 | 同上，验证付费意愿 |
| [超级简历 WonderCV](https://www.wondercv.com/) | 3000 万+用户，免费+会员制 | 中文市场需求已验证 |
| 人工简历修改服务（新华网/观察者网报道） | ~1200 元/小时；机构套餐 1.28-5.28 万元 | 高价服务锚点 → ¥9.9 报告显得极便宜 |
| 国内竞品形态 | WonderCV/WPS/讯飞等均为「在线编辑器+上传简历」 | **无纯本地、无私有的免费体检器** = 差异化空位 |

**用户原话素材**（用于 landing 文案，来自常识性高频抱怨，正式发布前应再做一手访谈）：
- "简历投出去石沉大海，都不知道是简历的问题还是岗位的问题"
- "不想把简历传到别人的服务器上"
- "就想知道哪里要改，不想再充一个月会员"

## 核心假设与信号强度

| 假设 | 证据 | 强度 |
|---|---|---|
| 求职者愿意为「知道自己简历哪里有问题」付费 | 竞品订阅价 + 人工服务价 | **强** |
| 「不上传简历」是真实顾虑（而非性能癖） | 隐私意识抬升 + 差异化空位 | 中（需 waitlist 验证） |
